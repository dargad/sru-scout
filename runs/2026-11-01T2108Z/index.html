LP: #2155998 · os-prober · Handle invalid grub config entries due to os-prober defaulting unidentified file system types

Issues

  • The problem is not yet understood or reproduced from the boot side. The original hanging-mounts bug was reportedly resolved separately with mount namespaces, so it is unclear the patch is needed or correct.
  • The regression-potential section is wrong. It claims os-prober is disabled by default, but it is enabled automatically at install time when other OSes are detected, so more users are exposed than stated.

  • The test plan only shows reproducing the bug on the old package. It has no explicit verification steps for the fixed package (no snapshot entry in grub.cfg) and no regression check that legitimate OS detection, such as a dual-boot with NTFS, still works.
