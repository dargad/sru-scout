Blocked SI-4583 LP 2155998 (os-prober) BLOCKED · Bhavya Dokuru

LP: #2155998 · os-prober · Handle invalid grub config entries due to os-prober defaulting unidentified file system types

Issues

  • The reviewer wants the problem understood and reproduced from the boot side before the patch can be judged. The original hanging-mount bug was reportedly fixed separately with mount namespaces, so the patch may be unnecessary or wrong.
  • The 'Where problems could occur' section is wrong. It says os-prober is disabled by default, but it is enabled automatically when other OSes are detected at install time. The regression assessment needs rewriting.
  • There is no analysis of what the fuseblk fallback actually does or which filesystems depend on it. Removing it could stop os-prober from detecting legitimate installs on filesystems grub-probe does not recognise, so the real regression potential is unquantified.
  • The test plan only shows the pre-fix reproduction. It has no steps to install the fixed package and verify the snapshot entry disappears, and no check that other filesystems (NTFS/fuseblk, other distros) are still detected.
  • The fix is proposed for Resolute only, and the Noble and Jammy backport is left as an unplanned follow-up. The upload targets and SRU scope for each series are unclear, and the hanging-mount fix is not yet in those series.
  • Development release is not fixed yet
