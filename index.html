Blocked SI-4583 LP 2155998 (os-prober) BLOCKED · Bhavya Dokuru

LP: #2155998 · os-prober · Handle invalid grub config entries due to os-prober defaulting unidentified file system types

Issues

  • The problem is not yet understood or reproduced from the boot/grub side. The reviewer wants a deeper analysis before accepting that the patch is correct. The original hanging-mount bug was later fixed differently, using mount namespaces, so this change may no longer be the right approach.
  • The 'Where problems could occur' section is wrong. It says os-prober is disabled by default, but it is enabled automatically when other OSes are detected at install time. The regression potential must be reassessed, including what the fuseblk fallback actually does, rather than removing it blindly.

This could hide real OS installs on legitimate but unrecognised filesystem types, such as NTFS via fuseblk. The test plan only covers LVM snapshots and does not check for this regression.
  • The SRU scope is unclear. The bug says the fix must also reach Noble and Jammy, but the original hanging-mount fix was never backported there. Which series are affected, and in what order the changes land, is not defined. The upload and test plan only cover the development series and do not address a verification path for the older releases.
